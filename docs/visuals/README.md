Created on 7 November 2026 with the built-in imagegen tool, using the approved Cheditte illustrated style: dark plum, cream and lime, bold sans-serif type and outlined isometric objects. The [prompt record](prompts.json) contains the generation and localization instructions. The original outputs are retained outside this repository.

The supplied SAP, Microsoft 365 and Active Directory artwork was used as the logo reference. Microsoft wordmarks were adapted to cream for contrast on the dark background; logos have no backing boxes. These are generated renditions, not pixel-identical copies of the source artwork. Other objects are generic illustrations, not additional product logos. No official endorsement is implied.

These illustrations explain the project; they are not application screenshots or evidence of successful tests. The Microsoft Graph and Teams Workflows routes stay separate. Excel cell operations remain marked experimental, with the Files dependency and support limitation visible. No credentials or tenant data appear here. Real screenshots were not modified.

The Entra ID module tile now includes a SAP/Entra comparison sheet. The new directory-choice images give on-premises **Active Directory** and cloud **Entra ID** equal prominence, with separate routes and program names. LDAP belongs to `abap-ldap-ad`, not Microsoft Graph. The shared comparison areas do not imply identical feature sets or a hybrid synchronization service. The AD tool's optional SAP locking is explained in the user guide; the Graph comparison diagram is read-only.

The editable EN/TR roadmap diagrams in `../img/walkthrough/` use the same palette; their Users entry now covers account, role and detail comparisons. The first-use diagram includes access, server and result-screen pictograms.
