Created on 7 November 2026 with the built-in imagegen tool, using the approved Cheditte illustrated style: dark plum, cream and lime, bold sans-serif type and outlined isometric objects. The [prompt record](prompts.json) contains the generation and localization instructions. The original outputs are retained outside this repository.

The supplied SAP and Microsoft 365 artwork was used as the logo reference. Microsoft’s wordmark was adapted to cream for contrast on the dark background; logos have no backing boxes. These are generated renditions, not pixel-identical copies of the source artwork. Other objects are generic illustrations, not additional product logos. No official endorsement is implied.

These illustrations explain the project; they are not application screenshots or evidence of successful tests. The Microsoft Graph and Teams Workflows routes stay separate. Excel cell operations remain marked experimental, with the Files dependency and support limitation visible. No credentials or tenant data appear here. Real screenshots were not modified.

The editable EN/TR roadmap diagrams in `../img/walkthrough/` use the same palette and retain their original wording. The first-use diagram includes access, server and result-screen pictograms.

Bu görseller, onaylanan mürdüm–krem–limon yeşili Cheditte diliyle hazırlandı. Görseller test kanıtı değildir; gerçek ekran görüntüleri değiştirilmedi. Graph ve Teams Workflows yolları ayrı gösterilir.
